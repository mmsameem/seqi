# SEQI Windows Installer

This repository now contains a pre‑built Windows installer for the SEQI application.

## Installer
- **File:** `SetupInstaller.exe`
- **Location:** `I:\SEQI_Final\SetupInstaller.exe`
- **Icon:** Uses `app.ico` (included).

## How to install
1. Double‑click `SetupInstaller.exe` (or run from a command line).
2. Choose the destination folder (default: `C:\SEQI`).
3. Select the desired options:
   - Desktop shortcut (recommended)
   - Start‑Menu shortcut
   - Launch SEQI after installation
4. Click **Install** and wait for the progress bar.
5. When the wizard finishes, click **Finish** (the app will launch automatically if selected).

## Uninstall
A `Uninstall.bat` script is created in the installation folder. Run it to remove shortcuts and delete the application directory.

## Requirements
- Windows 10+ (64‑bit)
- .NET Framework 4.6+ (already present on modern Windows)
- No external Node.js installation needed – the bundled `SEQI.exe` launches the embedded server.

## Troubleshooting
- If the installer reports missing files, ensure the `SEQI.Payload.zip` was successfully embedded (the build process already confirmed this).
- If shortcuts do not appear, run the installer with administrative privileges.
